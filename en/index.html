Which frame should I pick? What makes a good recording?
  • Place the camera side-on and level to the person; this is how trunk and arm angles are measured most accurately.
  • Record one cycle from start to finish (at least 2–3 cycles). Analyse the most demanding moments separately: the deepest bend, the highest reach, the moment the load is lifted.
  • Also record frequently repeated or long-held postures; an “average” frame also tells you about the job.
  • Save frames of the same task under the same task name ; the Records page then shows the timeline and the worst value together.

Each station × risk area is one row. Values are suggested from the method result; adjust them for your workplace with “Edit”. The table goes into the Excel and PDF reports as is.

Export / import

Excel report contains a summary, results and a separate sheet per method; download a task’s own report from its heading and a single record’s assessment form from its card. The CSV is in long format (one method result per row) and goes straight into an Excel or Power BI pivot. JSON is a full backup.

Excel download is not available in this view; use Copy CSV instead.
